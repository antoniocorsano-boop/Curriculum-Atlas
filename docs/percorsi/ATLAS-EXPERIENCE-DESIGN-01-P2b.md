# ATLAS-EXPERIENCE-DESIGN-01 / P2b — Adattatore di produzione InkJS
Stato: candidato da qualificare. Dipendenza MIT InkJS 2.4.0 fissata esclusivamente tra le dipendenze di sviluppo, fonte https://github.com/y-lohse/inkjs e https://www.npmjs.com/package/inkjs. API documentata: require("inkjs/full"), Compiler, Compile, Continue, currentTags. La sorgente Ink contiene le sei scene già esistenti senza riscrivere la storia. Il compilatore produce un contratto di presentazione JSON consumato dal componente di revisione. Il controllo CI rigenera in memoria e confronta esattamente il risultato; rifiuta campi mancanti, duplicati e scelte non autorizzate. Il comando di generazione è esplicito e non scrive durante i controlli. Il grafo, le scelte, gli stati, il traguardo e le autorizzazioni appartengono ad Atlas. Nessun compilatore nel client, nessuna rete richiesta dal fruitore, nessun dato personale, nessun nuovo servizio. Questo è un adattatore lineare di prologo, non ancora un importatore di storie ramificate.
Preflight: repository senza file di blocco delle dipendenze versionato; versione InkJS esatta. L'installazione e la prova effettiva del compilatore sono demandate alla qualificazione GitHub perché il registro pacchetti non è raggiungibile nell'ambiente locale. Phaser non installato in questa fase: valutazione separata di risorse, ciclo di vita, Canvas, accessibilità, fallback e prestazioni prima dell'integrazione. Nessuna modifica alla pubblicazione.
