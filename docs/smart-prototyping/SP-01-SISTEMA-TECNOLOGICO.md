# SP-01 — Pilota Smart: Analizzare un sistema tecnologico

Stato: PROTOTYPE_PREPARATION

Questo documento registra il primo caso pilota della lane Smart Prototyping definita in TRAMA issue #117.

## Obiettivo
Attività pubblica e mediata dal docente per classi terze: Energia, Ambiente, Sostenibilità.

## Sequenza
1. sistema scelto;
2. bisogno e funzione;
3. entrate → trasformazioni → uscite;
4. energia: fonte → ingresso → trasformazione → uscita utile + dissipata;
5. risorse;
6. ciclo di vita e impatti;
7. miglioramento sostenibile motivato;
8. riepilogo finale.

## Profilo runtime
- nessuna autenticazione;
- nessun database;
- nessuna telemetria studente;
- risposte esclusivamente locali nel browser;
- fruizione smartphone/LIM;
- nessuna dipendenza da Atlas Percorsi;
- nessuna promozione automatica.

## Fast gate
Caricamento, compilazione, persistenza locale, riepilogo, viewport smartphone/desktop, tastiera/focus essenziali, leggibilità e verifica di assenza di invio remoto delle risposte.

La materializzazione runtime deve avvenire su ramo dedicato prima di qualsiasi integrazione in main.
