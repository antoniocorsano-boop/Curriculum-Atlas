# EduTwin illustrated preview v0.1
C6/S3b.2 — implementation candidate; private teacher review only.
Parent #87, itself dependent on #81. Do not merge or deploy until the base and exact checks are qualified.

The existing Studio Atlas preview snapshot optionally carries edutwinMedia: revisionDigest, mediaDigest, bindings [{sceneId,assetId,alt,role}], images [{assetId,sha256,pixelWidth,pixelHeight,base64}]. Only the EduTwin reserved opening and SUMMARY/CHOICE scenes without stage are supported. All fields are bounded and closed; each binding refers to one existing scene and exact original WebP asset, with distinct image IDs and no URLs. Unbound scenes do not invent replacements. No new runtime or persistence.
mediaDigestInput uses fixed outer field order and the actual snapshot scene list, including metadata, revision digest and ordered arrays of binding/image metadata. The image digest is recomputed from bytes; header and pixel budgets checked before browser decoding. The receiver validates the snapshot and decodes the images before ACK. The bridge remains origin/channel-bound and transfers no content via URL; data exists only in the preview session. The digest binds content, not identity or review authority. Source review and production gates must still apply on Studio's side; a received snapshot does not grant authorization. runtimeAuthorized and studentAuthorized stay false.
The shared experience runtime renders the image for its current scene, captioned as setting, character or scene. No image is automatically assigned by similarity. Legacy snapshots retain the existing presentation. This is illustrated narrative and branching, not a complete simulation engine.
Tests use synthetic data: hash mismatch, invalid format and dimensions, missing or duplicate mappings, arbitrary URL, changed scene/digest, and actual mobile-width browser rendering through the existing bridge; altered payload cannot mount runtime. No private assets, no costs, no student release.
