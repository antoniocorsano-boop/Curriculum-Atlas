# Biblioteca Atlas — consegna Web integrata
19 novembre 2026. Priorità dell'ideatore: una biblioteca completa, fruibile, funzionale e visivamente convincente sul Web. Stop alla successione di laboratori isolati. Non replicare i nove bake per 45 campate.

## Prodotto
Riutilizzo della route reale /gateway/ del master nativo P1-spatial già integrato (#115/#121), con 45 campate, architettura, cupola, cielo, illuminazione, navigazione e tre portali; mantenimento della politica degli accessi. Baseline effettiva 25.798.660 byte per otto asset (run 44472237489); non confonderla con l'estrapolazione delle texture FLOAT32 della campata. In questa candidata vengono applicati direttamente nella route gli interventi M1/M2 della PR #114, run 44323263311 PASS: rugosità ottone e sette microstrutture con le mappe fotografiche esistenti, senza duplicare texture o geometrie. Conservare instanziazione, culling, controlli e fallback. Non integrare le texture COMBINED specifiche di posizione della #147 in tutte le campate; conservare il lavoro e i relativi risultati come risorse per dettagli selettivi. M2 è una resa Web approssimata, non parità con Cycles né approvazione estetica finale.

## Fruizione
Il workflow esistente produce la build Next standalone, confeziona la route effettiva e tutti gli asset, poi avvia e verifica il pacchetto, non un nuovo laboratorio. Il file atlas-web-linux-x64.tar.gz, se il workflow termina positivamente, è scaricabile negli artefatti GitHub. Su Linux x64 con Node.js 22: estrarre l'archivio, entrare in atlas-web ed eseguire node start-atlas.mjs. Aprire http://127.0.0.1:3000/gateway/ nel browser. Il programma usa solo loopback; nessun deploy o pubblicazione studenti. I portali seguono le politiche già esistenti; Studio rimane informativo. Su Android si usa il browser quando la candidata sarà servita da un host autorizzato; questo archivio non è un APK né una pubblicazione Web.

## Decisioni e limiti
Nessun nuovo motore, dipendenza esterna, servizio a pagamento o modifica di World Composer. Riutilizzo della verifica già esistente di route, navigazione, sei formati e fallback; niente cicli di ricerca separati. Il pacchetto completo ha priorità sui nuovi esperimenti; eventuali interventi successivi devono correggere problemi concretamente visibili nel prodotto e preservarne la fruibilità. I 25,8 MB sono la baseline delle risorse grafiche, non il peso del pacchetto applicativo. Non sono dimostrate le prestazioni fisiche, la qualità artistica finale, la riduzione a 5 MB o l'adozione dei bake LBC-01. La candidata resta privata/local-only; nessun merge o rilascio pubblico autorizzato. Gli artefatti CI temporanei non sostituiscono l'archivio durevole.
