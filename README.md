# Curriculum Atlas

Curriculum Atlas è la superficie pubblica di navigazione del curricolo e dei materiali didattici dell'ecosistema TRAMA.

## Stato S3-V2

- **F0 Foundation** — integrata
- **F1 Curricolo verticale + Materiali** — integrata
- **F2 Esplora relazionale** — integrata
- **F3 Materiali + Risorse** — integrata
- **F4 Mobile + LIM** — integrata
- **F5 Exit** — candidato alla chiusura finale

## Superfici pubbliche

- Home
- Curricolo
- Esplora
- Materiali
- Risorse
- Percorsi
- Obiettivi
- Raccordi

Atlas è progettato per uso pubblico su smartphone, tablet, desktop e LIM.

## Confini

- **Arena** resta l'autorità curricolare.
- **Atlas** pubblica e rende navigabili curricolo, relazioni e materiali.
- **Docente OS** resta il sistema operativo teacher-first.
- Non è autorizzato da S3-V2 alcun runtime Docente OS → Atlas.
- Nessun account, profilo individuale o tracking studente è richiesto.
- Le fixture presenti nel prodotto non devono essere interpretate come dati Arena live.
