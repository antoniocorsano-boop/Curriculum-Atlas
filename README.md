# Curriculum Atlas

Canonical repository for Curriculum Atlas.

The `main` branch remains stable. Active development is performed through reviewed work branches and pull requests.

## Ecosystem role

Curriculum Atlas is the semantic/public experience layer of the integrated education platform:

**CurManLight Arena governs → Curriculum Atlas makes the curriculum intelligible and navigable → Docente OS makes it operational.**

Atlas owns smart curriculum navigation, public/read-only views, Learning Object manifests, Visual Library, lesson-material discovery and public-safe provenance. It does not replace Arena as curriculum authority and does not become a private teacher workspace.

## Current product direction

The next product milestone is **ATLAS-P1 — Public Curriculum & Lesson Materials Hub**:
- Curricolo;
- Percorsi/UDA;
- Materiali delle lezioni;
- Smart Views / Mappa;
- Fonti & provenance;
- deep links to Docente OS.

The Spatial/Galaxy experience remains an advanced view, not the sole or mandatory entry point.
