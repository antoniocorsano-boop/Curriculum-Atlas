# Curriculum Atlas

Curriculum Atlas è la superficie pubblica di navigazione del curricolo e dei materiali didattici dell'ecosistema TRAMA.

## Stato S3-V2

- **F0 Foundation** — integrata
- **F1 Curricolo verticale + Materiali** — integrata
- **F2 Esplora relazionale** — integrata
- **F3 Materiali + Risorse** — integrata
- **F4 Mobile + LIM** — integrata
- **F5 Exit** — candidato alla chiusura finale sulla baseline corrente

La baseline corrente include l'export curricolare completo Arena e la sincronizzazione governata Arena → Atlas. Atlas non diventa per questo autorità curricolale: lo stato e la provenienza restano vincolati ad Arena.

## Superfici pubbliche

- Home
- Curricolo
- Esplora
- Materiali
- Risorse
- Percorsi
- Obiettivi
- Raccordi

Atlas è progettato per uso pubblico su smartphone, tablet, desktop e LIM.

## Confini

- **Arena** resta l'autorità curricolare.
- **Atlas** pubblica e rende navigabili curricolo, relazioni e materiali.
- **Docente OS** resta il sistema operativo teacher-first.
- Non è autorizzato da S3-V2 alcun runtime Docente OS → Atlas.
- Nessun account, profilo individuale o tracking studente è richiesto.
- Uno stato curricolare provvisorio deve essere mostrato come tale e non equivale ad approvazione.

## Documentazione S3-V2

La documentazione di fase è in `docs/`, incluso `S3-V2-F5-EXIT.md`.

La governance cross-product resta definita nel repository TRAMA Ecosistema.
