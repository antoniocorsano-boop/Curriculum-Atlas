## Confini

- **Arena** resta l'autorità curricolare.
- **Atlas** pubblica e rende navigabili curricolo, relazioni e materiali.
- **Docente OS** resta il sistema operativo teacher-first.
- S3-V2 non autorizza alcun runtime Docente OS → Atlas.
- Nessun account, profilo individuale o tracking studente è richiesto.
- Uno stato curricolare provvisorio deve essere mostrato come tale e non equivale ad approvazione.
