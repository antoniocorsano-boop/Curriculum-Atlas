# Curriculum Atlas

Canonical repository for **Curriculum Atlas**, the integral curriculum visualization and intelligent-navigation product of the TRAMA ecosystem.

Atlas is not only a Spatial/Galaxy visualization and not only a materials library. Its target role combines:
- navigable curriculum map and semantic graph;
- vertical/horizontal learning progressions;
- prerequisites, conceptual paths and interdisciplinary relations;
- Smart Navigation / “Chiedi ad Atlas”;
- public curriculum and Student Learning Hub;
- Learning Object and educational-resource library;
- curriculum ↔ objective ↔ lesson/publication ↔ resource links.

**Authority boundary:** Arena remains the curriculum authority. Atlas is authoritative only for its own resource identities, versions, publication/editorial state and navigable projections. Docente OS remains the teacher professional workspace.

Material production is not delegated to Docente OS's renderer. A specialist **Officina materiali** may create proposals from a teacher-approved brief, optionally using Atlas patterns, Learning Objects and design profiles. Publication into Atlas remains a separate explicit teacher-governed operation.

See:
- `docs/product/ATLAS_INTEGRAL_ROLE.md`
- TRAMA ADR-007 / ADR-008
- proposed TRAMA ADR-010

The `main` branch remains stable. Active development is performed through reviewed work branches and pull requests.
